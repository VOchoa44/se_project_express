# Express Backend API

**Intro**

Project Express is the backend for the WTWR (What to Wear?) application. It provides a RESTful API built with Express.js and connects to a MongoDB database using Mongoose. The project demonstrates server-side routing, request handling, middleware, controllers, models, and basic user authorization concepts.
**Technologies and Techniques Used**
JavaScript
Node.js
Express.js
MongoDB
Mongoose
Postman
Modular project architecture (routes, controllers, and models)

**Concepts Demonstrated**
RESTful API development
Express routing
Middleware
CRUD operations
Modular architecture (routes, controllers, models)
Request/response handling
